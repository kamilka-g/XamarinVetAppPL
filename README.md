
# Veterinary Appointment App 🐾

A simple mobile application built with **Xamarin.Forms** for booking veterinary appointments.  
Users can select a pet type, age (via slider), reason for visit, and preferred time. The summary is displayed after clicking the submit button.

## Features

- Choose between dog, cat, or guinea pig
- Dynamic age slider based on pet type
- Enter visit reason and preferred time
- Displays full appointment summary

## Technologies

- Xamarin.Forms
- C#
- XAML

## Design & Language

The UI/UX was implemented based on a static design image mockup.  
The app interface and text are in **Polish**.
